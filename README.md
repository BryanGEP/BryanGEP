### 🤖 Machine Learning & IA

Apps completas (backend + frontend + Docker) construidas alrededor de modelos de ML, varias desplegadas en Google Cloud:

- 🥑 **[Detección de enfermedades en aguacate](https://github.com/BryanGEP/deteccion-aguacate)** — Clasifica aguacates (sano / roña / antracnosis) con una CNN y Transfer Learning (VGG16).
- 🌸 **[Clasificación de flores](https://github.com/BryanGEP/clasificacion-flores)** — Reconoce 5 tipos de flores con una red convolucional.
- 😴 **[Detección de fatiga y somnolencia](https://github.com/BryanGEP/deteccion-fatiga)** — Visión por computadora con OpenCV para detectar bostezos y ojos cerrándose.
- 🔢 **[Reconocimiento de números](https://github.com/BryanGEP/reconocimiento-numeros)** — Dibuja un dígito y el modelo lo reconoce (MNIST, red densa vs. convolucional).
- 🎓 **[Predicción de egreso estudiantil](https://github.com/BryanGEP/prediccion-egreso)** — Predice la probabilidad de egreso de un estudiante según factores académicos.
- 🌡️ **[Conversor de temperatura con IA](https://github.com/BryanGEP/conversor-temperatura)** — Una red neuronal que aprende a convertir °C a °F.
- 📊 **[Análisis de datos y ML](https://github.com/BryanGEP/analisis-datos-ml)** — Colección de prácticas: EDA, pandas, perceptrón, redes neuronales y convolucionales.
