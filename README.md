Estudiante de **Ingeniería en Sistemas Computacionales** con especialidad en **Desarrollo de Aplicaciones Inteligentes Web-Móvil** en el Instituto Tecnológico de Jiquilpan (TecNM). ### Agentes de IA

Agentes conversacionales en Python, desde un chatbot base hasta agentes con *tool use* (function calling) que ejecutan acciones reales:

- **[Agente Conversacional (Groq)](https://github.com/BryanGEP/agente-conversacional-groq)** — Chatbot base en terminal con memoria de corto plazo (modelo `gpt-oss-120b` vía Groq). La base de la que nacieron los siguientes.
- **[Agente de Calendario (Claude)](https://github.com/BryanGEP/agente-calendario-claude)** — Gestiona Google Calendar en lenguaje natural con la API de Claude y *tool use*: crea, consulta, modifica y elimina eventos.
- **[Agente de Calendario (Groq)](https://github.com/BryanGEP/agente-calendario-groq)** — La versión gemela con la API de Groq, para comparar cómo cambia la integración entre proveedores.
- **[AgroIA](https://github.com/BryanGEP/AgroIA)** — Agente conversacional de apoyo al cultivo del aguacate (LangChain + FastAPI). Proyecto en equipo con metodología Scrum.

### Aplicaciones Web y Microservicios

- **[AgroIA-Web](https://github.com/BryanGEP/AgroIA-Web)** — Plataforma del agronegocio del aguacate: tienda en línea, asistente AgroIA y diagnóstico de enfermedades por imagen. Arquitectura de microservicios sobre Django.
- **[Microservicios](https://github.com/BryanGEP/Microservicios)** — Proyectos con arquitectura de microservicios usando NestJS, Prisma y un API Gateway.

### Machine Learning y Visión por Computadora

Aplicaciones completas (backend + frontend + Docker) construidas alrededor de modelos de ML, varias desplegadas en Google Cloud:

- **[Detección de enfermedades en aguacate](https://github.com/BryanGEP/deteccion-aguacate)** — Clasifica aguacates (sano / roña / antracnosis) con CNN y Transfer Learning (VGG16).
- **[Clasificación de flores](https://github.com/BryanGEP/clasificacion-flores)** — Reconoce 5 tipos de flores con una red convolucional.
- **[Reconocimiento de números](https://github.com/BryanGEP/reconocimiento-numeros)** — Reconoce dígitos dibujados a mano (MNIST, red densa vs. convolucional).
- **[Predicción de egreso estudiantil](https://github.com/BryanGEP/prediccion-egreso)** — Predice la probabilidad de egreso según factores académicos.
- **[Análisis de datos y ML](https://github.com/BryanGEP/analisis-datos-ml)** — Colección de prácticas: EDA, pandas, perceptrón y redes neuronales.
